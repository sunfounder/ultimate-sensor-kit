1.2 ライブラリのインストール
=============================

スケッチには **2 つ**のライブラリが必要です。1 つは Arduino IDE のライブラリマネー
ジャーから入り、もう 1 つは手動でダウンロードして追加します。

**Blynk ライブラリをインストールする**

#. Arduino IDE の **ライブラリマネージャー**を開き、``blynk`` を検索して
   **インストール**をクリックします。

   .. image:: ../img/blynk26_11_library.png
      :width: 80%

#. インストーラーは **BlynkNcpDriver** も要求します - **すべてインストール**を選び
   ます。

   .. image:: ../img/blynk_lib_blynk.png
      :width: 60%

.. note::

   このライブラリの名前は **BlynkESP8266** で、``ESP8266 wifi;`` を定義します。こ
   れらの名前は歴史的なもので、Blynk が何年も前に書かれたときのモジュールに由来し
   ます。ESPC2-01 でもまったく同じように動作します。このモジュールも AT コマンドに
   応答するからです。

**BlynkESP8266 ライブラリをインストールする**

このライブラリはライブラリマネージャーに入っていないため、GitHub からダウンロード
する必要があります。

#. `BlynkESP8266 <https://github.com/vshymanskyy/BlynkESP8266/archive/refs/heads/master.zip>`_
   をダウンロードします。

#. Arduino IDE で **スケッチ -> ライブラリをインクルード -> .ZIP形式のライブラリを
   インストール**を選びます。

   .. image:: ../img/blynk_add_zip_lib.png
      :width: 80%

#. ダウンロードした ZIP ファイルを選びます。事前に解凍する必要はありません。

   .. image:: ../img/blynk_choose_zip.png
      :width: 80%

#. ライブラリを追加したら Arduino IDE を再起動します。

.. note::

    このライブラリは古い 1.0 形式なので、IDE がバージョン番号を読めないという警告を
    出すことがあります。警告は無視してかまいません - スケッチは問題なくコンパイル・
    書き込みできます。
