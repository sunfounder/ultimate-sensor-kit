1.1 Blynk の設定
==========================

この章では、Blynk のアカウント、テンプレート、デバイスを 1 つずつ作成し、各プロ
ジェクトのスケッチの先頭に書く 3 行をコピーします。これは **一度だけ** 行います -
このキットのすべてのプロジェクトが同じテンプレートとデバイスを使い回します。

.. note::

    Blynk.Console の画面はときどき更新されます。以下のスクリーンショットは 2026 年
    のものです。ボタンの位置が違う場合は、正確な位置ではなく **フィールド名**（たと
    えば ``AUTH TOKEN``）を目印にしてください。

1. アカウントを作成する
-----------------------

#. `BLYNK <https://blynk.io/>`_ を開き、右上の **Sign Up** をクリックします。

   .. image:: ../img/blynk26_01_signup.png
      :width: 80%

#. メールアドレスを入力し、同意のチェックを入れて **Sign Up** をクリックします。

   .. image:: ../img/blynk26_02_email.png
      :width: 60%

#. 受信トレイを確認するよう案内が出ます。メール内の有効化リンクを開き、パスワード
   を設定します。

   .. image:: ../img/blynk26_03_password.png
      :width: 60%

2. テンプレートを作成する
-------------------------

**テンプレート** は設計図です。プロジェクトが送るデータと、ダッシュボードの見た目
を決めます。一度作成し、プロジェクトを進めながら追加していきます。

#. 左のサイドバーで **Developer Zone** を開き、**My Templates** を選んで **+ New
   Template** をクリックします。

   .. image:: ../img/blynk_new_template.png
      :width: 80%

#. テンプレートを設定します。

   .. image:: ../img/blynk_config_template.png
      :width: 80%

#. フォームを次のように入力します。

   * **NAME**: ``Ultimate Sensor Kit``
   * **HARDWARE**: **ESP32**
   * **CONNECTION TYPE**: **WiFi**

   .. image:: ../img/blynk_template_set.png
      :width: 80%

#. **Done** / **Save** をクリックしてテンプレートを保存します。

   .. image:: ../img/blynk_save.png
      :width: 40%

この時点でテンプレートは **空** です - データストリームもイベントもダッシュボード
もありません。これは意図的で、プロジェクトに必要なデータが決まった段階で追加します。

すべてのプロジェクトがこの 1 つのテンプレートを使うため、プロジェクトごとに **独自
の仮想ピン** を割り当てます。こうして互いに上書きしません。

.. list-table::
   :header-rows: 1
   :widths: 40 30 30

   * - プロジェクト
     - 仮想ピン
     - 用途
   * - 炎警報システム
     - V0
     - 炎センサーの値
   * - 侵入警報システム
     - V1 - V2
     - 留守モード、ステータステキスト
   * - 植物モニター
     - V3 - V6
     - 温度、湿度、土壌水分、LED
   * - 遠隔リレー制御
     - V7
     - リレーの状態
   * - 自動給水システム
     - V8 - V10
     - 土壌水分、しきい値、自動モード

番号を覚える必要はありません。各プロジェクトのページに使用するピンが書いてあります。

.. note::

   各データストリームには **2 つの名前** があり、Blynk はそれぞれ別の用途に使いま
   す。

   * **DATASTREAM NAME** - 技術的な名前で、たとえば ``away_mode``。API と MQTT が
     参照する名前で、小文字とアンダースコアで書きます。
   * **DISPLAY NAME** - ウィジェットやダッシュボードに表示される名前で、たとえば
     ``Away Mode``。Blynk が各単語の先頭を大文字にし、アンダースコアを空白に置き換え
     て自動的に作ります。

   そのため、データストリーム名が ``away_mode`` でもウィジェットには
   ``Away Mode (V1)`` と表示されます。以下のプロジェクトページでは画面に実際に表示
   される名前でウィジェットを指します。

3. デバイスを作成する
---------------------

テンプレートだけでは **認証トークンはありません** - トークンはデバイスが持ちます。
デバイスは実際のボードで、テンプレートを引き継ぎます。

#. 左のサイドバーで **Devices** をクリックし、**+ New Device** を選びます。

   .. image:: ../img/blynk_new_device.png
      :width: 80%

#. **From template** を選びます。

   .. image:: ../img/blynk_new_device_tem.png
      :width: 80%

#. テンプレート **Ultimate Sensor Kit** を選び、デバイスに名前を付けて **Create** を
   クリックします。

   .. image:: ../img/blynk_device_name.png
      :width: 80%

#. **New Device Created!** というウィンドウが開き、必要な 3 行が表示されます。

   .. image:: ../img/blynk_token.png
      :width: 80%

#. この 3 行を **正確に** コピーします。1 文字でも違うと、ボードは接続できません。

   .. code-block:: cpp

      #define BLYNK_TEMPLATE_ID   "TMPL..."
      #define BLYNK_TEMPLATE_NAME "Ultimate Sensor Kit"
      #define BLYNK_AUTH_TOKEN    "..."

   .. note::

      * ウィンドウを閉じても、**Devices** -> 自分のデバイス で同じ情報を確認でき
        ます。
      * トークンは **デバイス** に属し、テンプレートには属しません。後からテンプ
        レートにデータストリームを追加してもトークンは変わらないので、スケッチは
        そのまま動きます。

テンプレートとデバイスの準備ができました。次の章では、スケッチに必要な 2 つのライブ
ラリをインストールします。
