IoT-Projekte mit dem ESPC201
=================================

Das ESPC2-01-Modul vereint **WLAN und Bluetooth LE in einem Baustein**, deshalb kommt
dieses Kit für beide Arten von Projekten mit einem einzigen Funkmodul aus.

Das Modul ist **werkseitig mit der ESP-AT-Firmware programmiert**. Vor dem Start müssen
Sie nichts aufspielen.
