ESPC201 を使った IoT プロジェクト
=================================

ESPC2-01 モジュールは **Wi-Fi と Bluetooth LE を 1 つのモジュールに統合**しているため、
このキットは Wi-Fi のプロジェクトも Bluetooth のプロジェクトも同じ無線モジュールで
こなせます。

モジュールには **ESP-AT ファームウェアが工場出荷時に書き込まれています**。使い始める前
に書き込むものは何もありません。
