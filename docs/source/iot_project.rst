IoT-Projekte
====================

Dieses Kit wurde in zwei Versionen ausgeliefert, weil der Chip zwischenzeitlich knapp war:

* Eine **frühere Version** mit zwei Modulen - ein ESP-01 für WLAN und ein JDY-31 für
  Bluetooth. Die Anleitungen dazu finden Sie hier: :ref:`iot_projects_esp01`.

  .. image:: img/esp01_bluetooth_module.png
     :width: 600

* Die **aktuelle Version** mit einem einzigen ESPC2-01-Modul, das WLAN und Bluetooth in
  einem Baustein vereint.

  .. image:: img/espc201_module.png
     :width: 200
