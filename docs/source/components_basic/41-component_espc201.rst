ESPC2-01 モジュール
===============

.. image:: img/41_espc201.jpg
    :width: 400
    :align: center

ESPC2-01 は、Espressif Systems の **ESP32-C2**（ESP8684 としても販売されています）を
使った Wi-Fi と Bluetooth LE のモジュールです。1 つのモジュールで、このキットのプロ
ジェクトが使う Wi-Fi 接続と Bluetooth LE 接続の両方をまかないます。

内部では Espressif の **ESP-AT** ファームウェアが動作しており、シリアルポート経由の
AT コマンドで制御します。

モジュールは **キット付属の Wi-Fi アダプターに直接挿します** - ジャンパーワイヤーは
不要です。アダプターには 3.3V レギュレーターと、5V ボードと 3.3V モジュールの間の
レベル変換が入っています。

ESPC2-01 のピンと機能:

.. list-table:: ESPC2-01 のピン
   :widths: 20 80
   :header-rows: 1

   * - 名称
     - 説明
   * - 3V3
     - 電源、**3.3V のみ**。
   * - GND
     - グラウンド。
   * - EN
     - チップイネーブル。モジュール上でプルアップされています。GND に落とすとリセット。
   * - TX0
     - UART0 送信、GPIO20。モジュールからボードへのデータ。
   * - RX0
     - UART0 受信、GPIO19。ボードからモジュールへのデータ。
   * - IO9
     - ブートモード選択。**電源投入時**に GND へ落とすとダウンロードモードになります。
   * - IO2
     - 汎用 IO。このキットでは使用しません。
   * - IO3
     - 汎用 IO。このキットでは使用しません。

特長と仕様
-----------------------------------

* チップ: **ESP32-C2**（ESP8684H2）、シングルコア 32bit RISC-V
* Wi-Fi: 802.11 b/g/n（Wi-Fi 4）、**2.4GHz のみ**
* Bluetooth: **Bluetooth LE 5.0** - クラシック Bluetooth は非対応
* フラッシュ: **2MB**
* SRAM: 272KB
* ファームウェア: **ESP-AT v4.1.1.0**（Wi-Fi 用と BLE 用の AT コマンドを両方含むカスタムビルド）
* シリアル: **115200**、8 データビット、パリティなし、ストップビット 1、フロー制御なし
* モジュールの UART ピン: TX0 = GPIO20、RX0 = GPIO19
* 電源電圧: **3.3V**（5V ピンはありません）
* ピーク電流: Wi-Fi / Bluetooth の起動時に **400mA 以上**
* ロジックレベル: **3.3V** - ピンは **5V トレラントではありません**（絶対最大 3.6V）
* アンテナ: PCB アンテナ
* 寸法: **24mm x 14mm x 1.6mm**（ピンヘッダー半田付け時は高さ約 12mm）

.. important::

    モジュールは **3.3V** で動作し、ピンは **5V トレラントではありません**（絶対最大
    3.6V）。付属のアダプターがレベル変換を行うので、そのまま挿し込めます - アダプ
    ターなしで 5V の信号に接続しないでください。

    キットには **9V 電池**（または 6.5〜12V の DC 電源）も必要です。USB だけで給電
    すると、モジュールの起動時に 3.3V が落ちてしまい、AT コマンドに応答しません。
