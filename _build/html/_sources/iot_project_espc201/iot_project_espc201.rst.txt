IoT Projects with ESPC201
=================================

The ESPC2-01 module provides **Wi-Fi and Bluetooth LE in one module**, so this kit needs
only one wireless module for both the Wi-Fi and the Bluetooth projects.

The module is **programmed at the factory** with the ESP-AT firmware. There is nothing to
flash before you start.
