15. Bluetooth Remote Relay

A relay is a switch that is moved by an electromagnet, so a small signal can control a much bigger load. Send 1 and the relay closes, send 0 and it opens.

1. Build the Circuit

Warning

The relay in this kit switches small DC loads only. Never connect mains voltage while learning - 220 V can kill you and there is no need for it here.

Note

The module draws a high current at start-up, so make sure the 9 V battery or an external power supply is plugged into the DC jack of the R4 Minima.

  • Arduino UNO R4 Minima Board

  • ESPC2-01 Module

  • 5V Relay Module

2. Upload the Code

  1. Open the 15-Bluetooth_remote_relay.ino file under the path of ultimate-sensor-kit\code\iot_project_espc201\bluetooth\15-Bluetooth_remote_relay.

  2. Select Arduino UNO R4 Minima and the right port, then click Upload.

  3. Open the Serial Monitor at 115200. You should read:

    === ESPC2-01 Bluetooth (BLE) ===
[OK] BLE is ready - scan for "SunFounder-C2" on your phone
--------------------------------

    If you read [!] no reply from the module, the module is not answering on D0/D1 - check the four wires and the power supply.

3. Switch It from the Phone

  1. Open LightBlue, tap Scan and connect to SunFounder-C2.

  2. Expand the service 0xA002 and open the characteristic C304. Then tap Write new value.

  3. Set the format in the top right corner to UTF-8 String and type 1. The picture shows the field just before sending:

  4. Send it. The relay clicks, its indicator LED lights up and the Serial Monitor prints On.

  5. Type 0 in the same field and send it - the relay clicks back and the monitor prints Off. The picture shows the field again:

    Note

    Some relay modules work the other way round: they switch on when the pin is LOW. If yours clicks the opposite way, swap HIGH and LOW in the sketch.

4. Code explanation

  1. One pin, one switch

    const int relayPin = 8;

pinMode(relayPin, OUTPUT);
digitalWrite(relayPin, LOW);

    Writing LOW in setup() matters: a pin that has just become an output may start HIGH for a moment and make the relay click every time the board resets.

  2. The command check

    if (message == '1') {
  digitalWrite(relayPin, HIGH);
  Serial.println("On");
} else if (message == '0') {
  digitalWrite(relayPin, LOW);
  Serial.println("Off");
}

    Same shape as the lock project: the state comes from the phone, and anything that is not 1 or 0 is ignored.

  3. Why the relay is not driven directly from the phone

    The phone talks to the module, the module talks to the board over two wires, and the board drives the relay. Each step only passes a short command along - that is why a single character is enough even though three devices are involved.
