14. Bluetooth OLED

Type on the phone, read it on a 128 x 64 OLED display. This project is close to the LCD one, but the display is smaller and the sketch has to guess when a sentence is finished - the phone sends characters one after another, not as one block.

1. Build the Circuit

Note

The module draws a high current at start-up, so make sure the 9 V battery or an external power supply is plugged into the DC jack of the R4 Minima.

  • Arduino UNO R4 Minima Board

  • ESPC2-01 Module

  • OLED Display Module

2. Upload the Code

  1. Open the 14-Bluetooth_oled.ino file under the path of ultimate-sensor-kit\code\iot_project_espc201\bluetooth\14-Bluetooth_oled.

    Note

    Install Adafruit SSD1306 and Adafruit GFX Library from the Library Manager.

  2. Select Arduino UNO R4 Minima and the right port, then click Upload.

  3. Open the Serial Monitor at 115200. You should read:

    === ESPC2-01 Bluetooth (BLE) ===
[OK] BLE is ready - scan for "SunFounder-C2" on your phone
--------------------------------

    If you read [!] no reply from the module, the module is not answering on D0/D1 - check the four wires and the power supply.

3. Send Text from the Phone

  1. Open LightBlue, tap Scan and connect to SunFounder-C2.

  2. Expand the service 0xA002 and open the characteristic C304. Then tap Write new value.

  3. Set the format in the top right corner to UTF-8 String and type Hello. The picture shows the field just before sending:

  4. Send it. The word appears on the OLED and in the Serial Monitor.

  5. Send another word - it replaces the first one, the display does not scroll.

    Note

    Two rules decide when the message is complete: either you end it with #, or you simply stop typing. The sketch waits 120 ms of silence and then treats what it has as one message.

    The display is 21 characters wide and 4 lines high. Longer text is cut off.

4. Code explanation

  1. The display

    display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
display.clearDisplay();
display.setTextSize(1);
display.setTextColor(SSD1306_WHITE);
display.setCursor(0, 0);
display.print(message);
display.display();

    0x3C is the I2C address of the module. Nothing shows up until display.display() is called - the sketch writes into a buffer first and pushes the buffer to the screen in one go.

  2. Deciding when the text is finished

    if (c == '#' || c == '\r' || c == '\n') {
  showMessage();
  continue;
}
message += c;
lastByte = millis();

    A # finishes the message at once. A line ending does the same, because some apps add one automatically.

  3. The 120 ms rule

    if (message.length() > 0 && millis() - lastByte > 120) {
  showMessage();
}

    BLE sends the characters of one write in a burst, with almost no gap. When the burst stops, 120 ms pass and the sketch shows what it has. This makes typing on the phone feel natural without pressing anything.

  4. Clearing afterwards

    message = "";

    Without this the next word would be appended to the old one and the display would grow longer and longer until it is cut off.
